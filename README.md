# 인천 피스캠프 2026

GPS 위치 기반 퀴즈 트레킹 웹앱. 빌드 없이 정적 파일로 동작합니다.

## GitHub Pages

저장소 Settings → Pages → Deploy from a branch → main / (root) → Save.

사이트 주소: https://bttrlvs.github.io/ipc2026/

## 기능

- 이름 입력, GPS 현재 위치 깃발, 4개 퀴즈 포인트
- 반경 35m 도달 시 퀴즈 표시 (보고된 GPS 오차 80m 이하)
- 이름과 퀴즈 진행상황은 기기 브라우저에만 저장
- 도보 경로선은 정확한 GPS 트랙 반영 전까지 표시하지 않음

다른 도메인에서 저장된 브라우저 진행상황은 자동 이전되지 않습니다.
